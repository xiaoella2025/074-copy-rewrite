# 074 · 图文视频工作流

074 是独立运行的本地工具。当前优先实现图文工作流；HTML 动画视频和音乐 MV 尚未接入。1.24.0 拆解包用于核对流程和界面，不能替代原软件的服务端或剪映侧验证。

074 自用，不需要激活码或软件订阅。LLM、绘图和配音使用用户自行配置的服务商 API；服务商可能单独计费。

## 启动与数据

双击 `Start074.cmd`，或运行 `python server.py`，然后打开 <http://127.0.0.1:18801/>。系统设置在 `/settings.html`，任务列表在 `/tasks.html`。074 的配置和任务只写入本项目的 `data/`，不读取 071、072、073 的目录。

首页按 1.24.0 的任务入口展示图文、HTML 动画视频、音乐 MV 三类。当前图文入口进入完整设置表单；另外两类会在首页说明接入状态。图文表单采用深色宽版分组布局，封面可选择不生成、带标题、留白或本地上传。封面标题、副标题、模板和比例会随生成请求提交。
任务列表使用同一套深色侧栏布局，并默认打开最近任务。图文全链路完成后进入独立的 `/result.html?task=<任务编号>` 结果页；任务列表也能打开该页，结果按已保存产物显示，可返回任务详情人工修改或继续未完成阶段。

启动器会复用已经运行的 074；同一端口只允许一个服务实例。改动 `server.py` 后，需先结束旧服务再启动，新页面文件可能先于旧进程更新，不能仅凭页面外观判断后端已更新。

先在系统设置配置所需的 LLM、TTS、绘图服务和剪映草稿目录。凭据保存在本机 `data/settings.json` 与 `data/profiles.json`，不会返回给普通设置查询接口。开发和离线测试使用假凭据与本地替身，不调用付费服务。

LLM 配置页支持自动保存和底部的「保存配置」按钮。保存后会显示本机保存状态；刷新设置页可看到已保存的配置和 Key 的脱敏状态。编辑其他字段时留空 API Key 会保留原值，重新输入才替换。若早期版本已把脱敏字符串误写入配置，页面会显示为缺少 Key，需要用户在本机重新填写。连接测试在输入框留空时使用当前配置已保存的 Key。

## 图文流程

执行顺序是文案预审 → 改写 → 元信息 → 分镜 → 配音 → 绘图提示词 → 出图或取素材 → 剪映草稿。支持全自动、半自动、直接出片；可选择 AI 绘图、素材库、网络素材和自定义绘图接口。配音支持火山、MiniMax、Aura Studio、上传音频和双人播客；动态分镜需要本机 `ffmpeg`。

语音识别可选云端火山或本地 SenseVoice。云端复用 TTS 配音中的火山 API Key，并需要账号开通「录音文件识别 2.0」；本地识别需要在 `data/models/asr/` 放置 `model.int8.onnx`、`tokens.txt`、`silero_vad.onnx`，并安装 `sherpa-onnx` 与 ffmpeg。上传整段配音时，识别可用则按时间轴对齐镜头；识别不可用或文本差异过大时按文案字数切片，结果中的 `duration_source` 会标明方式。续跑只补缺失的音频和图片。

本地识别的模型和运行库保存在本机 `data/`，不随 Git 推送。已有 `软件/models.zip` 时，可只提取压缩包内 `asr/` 的三个文件到 `data/models/asr/`；运行库可用 `python -m pip install --target data/runtime sherpa-onnx==1.13.8` 安装。装好后在设置页点「重新检测」。切换本地或云端识别方式时会立即保存；绿点表示当前所选方式的本机配置已就绪，云端账号权限仍须由服务商实际响应确认。

在任务列表中可人工修改改写稿、分镜和绘图提示词，或选择单镜重画。保存会生成新的任务版本并进入续跑页面；原任务与已有剪映草稿保留。暂停后也可从任务列表继续。素材库未分配镜头且关闭 AI 兜底、动态分镜失败等情况会停止流程，避免生成缺素材草稿。
