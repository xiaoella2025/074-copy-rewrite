# 封面主副标题多行修复

用户明确要求取消副标题最多两句的限制，并让主标题支持换行。

- 去掉副标题数组最多两项的硬限制及元信息阶段的前两项截断；保留文字类型、主标题200字和副标题每行300字校验，不静默裁剪。
- 新建任务、步骤参数、封面卡、创作页与画图实验室统一使用多行主标题输入；副标题按回车分行。
- 生成提示词保留行顺序，明确逐行横排；有手动换行时替换内置模板中“所有字同一行”的冲突文字。单行标题维持原模板。
- 先验证保存、初次封面入口和实际提交提示词，供应商用本地模拟；不自动重做正式图片、配音或提交收费生成。
- 安装只更新经过哈希核验的相关资源/函数；后端仍运行时先完成候选验收，等待用户正常退出再安装。
