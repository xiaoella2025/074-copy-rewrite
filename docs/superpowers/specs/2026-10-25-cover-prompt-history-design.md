# 封面提示词查看修复

用户反馈封面文字有错，并且编辑/复制提示词看不到内容。只读记录表明：没有持久化构图方向，旧提示词仍在缓存中，但参数变化使缓存键失效，界面拿到空字符串。

- 当前参数有效的提示词继续放在prompt；旧任务/封面/缓存中的提示词作为lastPrompt返回，明确为历史内容，不因参数变化而隐藏。
- 编辑框无当前提示词时展示“上次保存的提示词”，可以查看和复制。历史内容未经修改不能直接提交，避免复用旧文字；用户明确修改并点击出图才提交一次性提示词。
- 排队生成期间也可查看、复制，禁止修改和再次出图。没有任何历史时明确说明需先生成构图方向。
- 不把失效缓存重新标成有效，不自动调用LLM或生图，不改变已有图片和回执。保存封面文字本身不会改写图片像素。
- 临时任务验证历史保留、当前参数隔离和提交保护，安装按现有后端退出流程执行。
