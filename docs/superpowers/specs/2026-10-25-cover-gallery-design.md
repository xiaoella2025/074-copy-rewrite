# 封面画廊与可见提示词

用户要求：封面提示词像其他提示词一样直接可见；在“分镜画廊”旁增加“封面画廊”，操作沿用分镜画廊。已完成任务仍在历史，修改另建任务。

## 采用方式

复用现有任务详情页、封面编号和分镜图片编辑组件，增加同级页签，不新增独立实验页。只把现有封面卡展开不能提供画廊操作；另做一套任务/出图系统会造成参数与回执分叉，两种方式均不采用。

## 页面与操作

- 页签顺序：产物预览、配音试听、分镜画廊、封面画廊、字幕断行。产物预览保留现有封面入口。
- 第一张封面及已启用/已有记录的第二张封面分别显示。未启用第二张时不额外创建或生成。
- 每张封面直接展示完整提示词，保持换行、可选择、可复制；不再需要先点“编辑提示词”才能查看。当前图片实际使用的提示词与当前参数准备出图的提示词分别标明，不能用后改参数冒充旧图的来源。没有保存的提示词明确说明，不能凭图补造。
- 封面图支持点击放大、下载、裁剪、参考图编辑、图片历史/换回、上传替换；保留编辑封面文字、编辑提示词和重新生成入口。两个封面槽位保持各自设置及图片，不与分镜编号混用。
- 裁剪、替换、重新生成和历史恢复前保留旧图及其提示词、来源信息，沿用分镜画廊保留最近5个版本的约定。首次安装只登记现有图片，无法恢复过去已覆盖且无存档的版本。
- 参考图编辑沿用现有弹窗、素材库和供应商能力校验。生成前显示所用引擎及计费提醒；不支持图片编辑的引擎明确说明并阻止提交，不悄悄切换平台。

## 原任务与在途保护

- 查看、复制、下载只读；已完成任务首次修改前创建新任务并跳转，历史原成品、配音和成功分镜图片不改动。未完成任务仍在本任务修改。
- 生成中/回执未知仍能查看提示词和查询原任务，不能借裁剪、替换或切换页面抹去在途回执。操作编号防止双击/响应丢失导致重复生成。
- 本地裁剪、上传、恢复不调用模型。只有用户明确点击生成/参考图生成才可能扣费。

## 验收与交付

临时任务和模拟供应商验证：页签、双封面显示、提示词与图片版本匹配、复制下载、裁剪恢复、参考图能力拦截与重复提交保护；已完成原任务全文件哈希不变，修改进入新任务。通过实际桌面入口的隔离界面验收后，与待安装的历史任务保护修复合并更新，不提交真实付费生成。安装前仍需正常关闭074。
