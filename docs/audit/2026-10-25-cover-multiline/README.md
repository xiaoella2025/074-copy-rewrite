# 封面主副标题多行修复

2026-10-25：用户确认保存并正常退出074后，已完成安装和安装后复核。

## 原因

封面失败发生在本地参数校验：task_cover.validate_options把副标题数组数量写死为2；server.step1_meta又把手填副标题截断为前两项。主标题的多个输入入口为单行input，电影海报内置布局又要求所有字在同一水平行，输入和提示词都不支持用户要的多行排版。

## 改动与效果

- 取消副标题最多两行和元信息前两项截断。三行及更多副标题按行完整保存。保持文字类型、主标题200字、副标题每行300字的原有长度保护；不静默裁剪。
- 新建页、步骤参数、封面卡、HTML/MV创作页、画图实验室的封面主标题均用textarea；帮助文字说明可回车换行。
- 多行主标题在提交提示词中保留原文及行顺序，移除电影模板冲突的“所有字同一行”；明确每行横排、手动换行优先。单行标题保持原提示词。
- 多行副标题在提示词中明确每段占一行。极简模板原来的“一行排副标题”也会按用户分行调整。
- 保留封面在途查询、幂等复用、旧图片和配音保护。没有自动重做正式任务。
