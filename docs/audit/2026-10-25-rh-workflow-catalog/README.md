1. **内置5项**：原Qwen两项保留，增加热门FLUX、Qwen中文海报优选、SDXL基础备选。不自动改用户默认。

3. **封面和内页分别选**：新建、改参数、封面卡、创意流程、画图实验室都提供工作流选择。保存到任务自己的image.workflow/cover.workflow或创意配置；恢复任务及参数复用保留这些选择。

5. **每套单独核对**：每个key独立保存完整图、指纹、来源、核对和网页跑通确认。凭据变化使旧核对失效。普通续跑仍查询旧taskId，不因系统切换而重复生图。
