# 08：封面文字模型、自定义模板与双封面设置

## 状态与范围

用户确认在现有紧凑封面卡中增加文字模型选择、复用模板库支持自定义模板，两张封面分别保存。本次已同步安装版并正常启动；没有重跑正式任务或调用真实提供商。01–06 的已完成功能保留，08 中的图库/即梦参考编辑及其他较早差异不据此判定完成。

## 每项功能如何实现

| 功能 | 实现方法 | 使用方法 |
|---|---|---|
| 独立封面文字模型 | 卡片沿用已保存的模型档案列表，只返回 ID、名称、模型名；每个封面分别保存 override，空值跟随任务。显式生成构图及缺构图时的工作流/断点续跑均消费这一选择；旧队列快照不覆盖手动设置 | 在封面卡顶部紧凑下拉框中选择。选择只保存，点“生成构图方向”才发文字请求 |
| 自定义封面模板 | 现有 TemplateStore 增加 covers 类型，内置项直接取既有 coverTemplates；构图、主副标题排版、留白要求、预设方向通过类型/长度校验后写入原 template-library.json | 点“自定义模板”，编辑后“保存为新模板”。从当前模板复制，新增可复用版本，不产生模型请求 |
| 两张封面独立保存 | cover-editor.json 的 1/2 节点各自保存模型、模板、构图结果和标题等；每张封面保存模板快照，模板库之后修改或删除不会静默改变旧任务。第二张标题/构图不改第一张公共元数据 | 两张卡分别设置；刷新页面后保留。第一张主标题原有公共元数据写回行为继续保留 |
| 切换模板不暗中生成 | 模板按钮从 directions 动作改为 save；“生成构图方向”作为显式动作常驻。没有构图记录且换了模板时不把旧作业完整提示词误当新模板提示词 | 先选模板，再明确生成构图和封面 |
| 已付费封面恢复 | 原作业完成且图片仍在时按同 operation ID 直接返回；已有结果的下载恢复先消费本地结果，不先加载当前绘图凭据。只有供应商编号而无结果时继续校验原凭据 | “查图”和同一操作重试复用原作业，不因此再购买 |
