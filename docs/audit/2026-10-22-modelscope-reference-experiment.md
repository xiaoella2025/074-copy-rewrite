# 魔搭参考图：独立可关闭实验

## 用户确认的范围

用户要求保留原有魔搭及其他生图选择，新增可单独测试、效果不满意即可关闭的功能。为此只新增独立实验，不自动接管任务，不修改原有文生图、任务模式、封面或分镜编辑行为。

## 功能与效果

- **入口**：系统设置 → AI绘图 → 魔搭社区 →「独立测试魔搭参考图（实验）」。
- **默认关闭**：独立开关保存在独立实验目录中，启用和关闭不改变当前生图引擎、文生图模型、Token、备用平台及已有任务配置。
- **一次一张**：本页选择一张PNG/JPG/WEBP，填写编辑要求，明确点击「生成1张测试图（消耗魔搭额度）」才向魔搭提交。暂不接入生产流水线或批量任务。
- **独立编辑模型**：固定使用 `Qwen/Qwen-Image-Edit-2511`，沿用现有魔搭Token，通过官方异步接口提交文字和 `image_url` 数组。原有魔搭文生图模型不变，不自动切换其他供应商。
- **防重复提交**：提交前记录本地操作ID、输入指纹、原始图片和账户指纹；返回平台任务ID后保存。重复操作复用记录；在途或提交结果不明时禁止新提交。
- **查回已有结果**：轮询只查询原平台ID，先保存图片地址再下载。下载失败仍保留原结果；查询与刷新不再购买。关闭开关后仍可手动查询已经提交的任务，图片和记录保留。
- **限流与异常区分**：明确HTTP429、认证或参数拒绝可由用户修改后另开测试。真正的超时、未知提交不自动重发，需要核对平台记录。错误不暴露Token或供应商原始响应。
