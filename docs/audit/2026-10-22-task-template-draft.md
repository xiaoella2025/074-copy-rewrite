# 新建页自定义模板选择与草稿恢复修复

## 用户要求及根因

用户复刻并保存人物故事提示词模板后，在新建任务中找不到选择入口；同时要求新建任务不自动填入旧文案，点击开始制作时应保存填写内容，以便失败后恢复。

- 正式模板库只读核查确认已有自定义人物故事模板；未删除、覆盖或迁移模板内容。
- 提示词选择框原先嵌在改写强度区域，`story_form_layout.js` 会在半自动与直接出片模式隐藏整行，导致已保存模板存在但入口不可见。
- `task_form_recovery.js` 原先对普通新建页自动恢复草稿；即便新建页没有修改，离开页面也会无条件保存，无法区分空白新建与主动恢复。

## 实现与效果

1. 将原提示词模板选择框移到内容赛道下面，保留同一控件、模板目录与快照提交逻辑。全自动、半自动、直接出片均能选择自定义模板，不改变三种模式的生成行为。
2. 新建页不自动恢复草稿，继续提示有草稿可恢复；用户明确点击后等待设置及模板准备好，再恢复文字、参数和匹配的附件缓存。
3. 保留编辑后自动暂存；仅有真实表单修改才在离开时写入，打开或关闭空白新建页不会覆盖旧草稿。
4. 保存草稿和开始制作均强制刷新当前快照；提交发生在保存完成之后。预检或提交失败不会清除快照，恢复时不自动提交生成请求。
