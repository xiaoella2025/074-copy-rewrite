# 画图实验室离页继续与返回恢复

问题：生成使用单次长 POST；页面内的 busy、草稿和返回结果均不持久。后端即使完成，离页后的客户端也收不到结果；重新进入只读取已完成图片，没有待处理任务。

修复：
- 显式 background 提交先原子保存实验室任务回执，再启动独立线程，立即返回提交编号。既有同步调用保持兼容。
- 相同提交编号及内容只执行一次；同编号不同内容拒绝。响应丢失后保留客户端提交编号，防止同内容重试重复购买。
- 排队、执行、失败、图片结果及平台返回的上游任务编号保存在本地，逐张保存；不保存 API Key。
- 返回页面从后端恢复状态，运行时每 2.5 秒读取结果；新增只读“刷新进度和结果”。IndexedDB 保存文案、参考图、模板、风格、引擎和工作流等草稿。
- 软件退出与页面切换分别处理：切换页面不中断线程；进程重启后的未完成回执显示结果待核对，不自动再次购买。
